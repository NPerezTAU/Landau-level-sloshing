# Landau-level-sloshing

This Python script numerically integrates the Schrödinger equation of the 1D harmonic oscillator with a time-dependent frequency. Then we analyze the observables that characterize the sloshing oscillations: pseudo-energy partition, mass flux, and the function $\Gamma(t)$. The resulting plots are used in the paper (Figures 5 and 6).

The script uses the Dedalus solver (second version) [Burns, Keaton J., et al. "Dedalus: A flexible framework for numerical simulations with spectral methods." Physical Review Research 2.2 (2020): 023068.].
