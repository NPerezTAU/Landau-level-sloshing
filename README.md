# Landau-level-sloshing

This Python script integrates the Schrödinger equation of the 1D harmonic oscillator with a time-dependent trapping frequency. We analyse the observables that characterise the sloshing oscillations: pseudo-energy partition, mass flux, and the function $\Gamma(t)$. The resulting plots are used in the paper "Landau levels in a time-dependent magnetic field: the Madelung fluid perspective" by N. Perez and E. Heifetz (Figures 5 and 6). The parameters used to make those figures are indicated in the script (commented out).

The script uses the Dedalus solver (second version) [Burns, Keaton J., et al. "Dedalus: A flexible framework for numerical simulations with spectral methods." Physical Review Research 2.2 (2020): 023068.].
